# Ahsan Ullah – MERN Stack Developer Portfolio

A modern, responsive, and animated **single-page portfolio website** built with **React** and **Tailwind CSS** to showcase my skills, projects, and experience as a MERN Stack Developer.

🔗 **Live Demo:**  
http://ahsan-portfolio-bucket.s3-website.ap-south-1.amazonaws.com

---

## 📌 Features

- Single-page smooth scroll navigation
- Fully responsive (Mobile, Tablet, Desktop)
- Scroll reveal animations using Framer Motion
- Interactive project cards with hover effects
- Downloadable CV
- Clean and professional UI design
- Deployed on AWS S3 (Static Website Hosting)

---

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- HTML5
- Tailwind CSS

### Animations
- Framer Motion
